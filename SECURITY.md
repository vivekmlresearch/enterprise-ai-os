# Security policy

This is an offline portfolio prototype, not a hardened enterprise deployment. Do not submit credentials, private records or regulated data. No paid models or real payments are connected. Browser history is local, mutable and quota-limited.

Before adding external tools/models, implement tenant authorization, rate limits, cost ceilings, input/output contracts, restricted egress, tool sandboxing, secret storage, approval records and adversarial tests. See the architecture roadmap. Report a suspected vulnerability privately to the repository owner's verified contact channel; avoid posting exploit secrets in public issues.
